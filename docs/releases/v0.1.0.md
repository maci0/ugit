Initial ugit release: a pure Zig client for the Git command forms used by
Moonraker and Phobos update and version-discovery paths.

- Static Linux x86-64 and ARMv7 Cortex-A7 hard-float binaries.
- Smart HTTP(S), verified SHA-1 objects and packs, filtered clone and lazy blobs.
- Caller-focused conformance tests, Debug/ReleaseSafe unit tests, and MISRA-Zig checks.
- GPL-3.0-only; the bundled Zig notice covers the MIT-licensed standard library.

Each archive includes `bin/ugit`, build metadata, licenses, and the command
contract. Verify `SHA256SUMS` before extracting. The ARM artifact is cross-built;
it has not been executed or memory-profiled on the printer. Pack buffering can
exceed the printer's free RAM. Supported repository formats and other bounds
are documented in `docs/CONTRACT.md`; this release is not a blanket replacement
for the system Git installation.
